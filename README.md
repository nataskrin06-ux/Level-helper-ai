# Level Helper (мод для Geode)

Кнопка «Helper» у лівому верхньому куті головного меню. Пишеш запит
(наприклад: `easy 10` або `hard long`), тиснеш Preview, бачиш список шматків, що будуть
поставлені, і тиснеш Create або Stop. Рівень з'являється у «Створені».

## Статус
Це ВИХІДНИЙ КОД, не готовий файл. Я не міг його скомпілювати чи запустити.
Можливі помилки в назвах функцій Geode, їх виправляє збірка (текст помилки видно в GitHub Actions).
Версія гри: Geode зараз працює лише з 2.2081, а в тебе 2.208, тому мод запуститься лише після оновлення гри.

## Як зібрати через GitHub (без ПК)
1. Створи акаунт на github.com і новий репозиторій.
2. Завантаж усі файли з цієї папки (разом з папкою .github).
3. Відкрий вкладку Actions, запусти «Build Mod» (Run workflow).
4. Коли збірка закінчиться, завантаж артефакт «Build Output»: усередині файл .geode.
5. Поклади .geode у папку mods Geode (або відкрий його через Geode) і перезапусти гру.

## Чого ще немає
Голосу й чату з ШІ, декорацій і підсвітки наступного блока в редакторі. Є лише список шматків у Preview.
