CHATGPT GD BOT — проект Android v0.1.1

Что есть в этой сборке исходников:
- стартовый экран приложения;
- запрос разрешения Android на отображение поверх других приложений;
- плавающая панель, которую можно перетаскивать;
- кнопки AUTO PLAYER, PRO MODE, CHEATER MODE, AI BUILDER, REMIX MODE, LEVEL CHECKER;
- поле команды, которое теперь временно включает фокус окна для показа экранной клавиатуры;
- кнопка СТОП;
- уведомление foreground service, пока панель включена.

ВАЖНО: это пока рабочая оболочка интерфейса, а не готовый APK и не полноценный игровой бот.
Кнопки режимов пока не выполняют игровые действия. Не реализованы автоматические нажатия,
распознавание экрана, прохождение уровней, построение уровня внутри редактора GD,
ремикс и анализ уровня. Для этих возможностей потребуется отдельная разработка,
а некоторые функции потребуют разрешений Android и тестирования на устройстве.

Сборка:
- JDK 17
- Android SDK Platform 35
- Gradle / Android Gradle Plugin 8.7.3
- открыть проект в Android IDE и собрать debug APK.

Ограничения и безопасность:
- отдельное приложение, не Geode-мод;
- не меняет файлы Geometry Dash;
- не удаляет аккаунты, уровни, приложения или моды;
- не загружает и не публикует уровни от имени пользователя.
